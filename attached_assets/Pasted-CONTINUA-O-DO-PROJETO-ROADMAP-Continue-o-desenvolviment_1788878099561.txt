FASE 3 — MORPHIN / ANIMAÇÕES
==================================================

Analise:
https://morphin.dev/

Use os componentes e padrões de movimento do Morphin como referência.

NÃO adicionar animação apenas por estética.

Priorize:

1. NAVEGAÇÃO

Adaptar o conceito de:
Animated Navbar Menu with Morphing Hover State

para a sidebar.

Aplicar transição suave no item ativo e hover.

2. RESULTADO DA CALCULADORA

Quando um novo resultado aparecer:

• fade + pequeno movimento vertical;
• duração curta;
• valor atualizado suavemente.

3. RESISTOR

Ao recalcular a resistência:

• animar suavemente a mudança das bandas;
• não fazer o resistor girar ou usar efeitos exagerados.

4. TOASTS

Usar como referência:
React Ripple Animation in Toast

Aplicar para:

• cálculo realizado;
• dados salvos;
• erro;
• aviso.

O feedback deve ser curto e elegante.

5. LOADING

Usar inspiração do:
Parametric Orbit Loader

somente em ações assíncronas futuras como:

• login;
• CEP;
• tarifa;
• carregamento inicial.

Utilizar versão discreta.

6. DASHBOARD

Quando o dashboard receber dados reais, usar como inspiração:

• Animated Dashboard Performance Chart
• Animated Dashboard Chart UI

Animar entrada dos dados e atualização dos gráficos.

Não exagerar nas animações.

7. HISTÓRICO

Usar como inspiração:
Animated Status Badge with Table for Dashboards

para histórico, estados e informações tabulares.

8. RECOMENDAÇÕES FUTURAS

Animated Expandable Card Stack poderá inspirar cards expansíveis de recomendações.

Não implementar recomendações agora caso essa fase ainda não tenha sido iniciada.

REGRAS DE MOTION:

• microinterações de aproximadamente 150–300ms;
• preferir transform e opacity;
• evitar movimentos que mudem layout;
• respeitar prefers-reduced-motion;
• animações nunca podem atrasar a utilização.

Se algum componente do Morphin for PRO ou não estiver disponível, NÃO tente contornar acesso.
Apenas reproduza um padrão de movimento equivalente usando Framer Motion.
